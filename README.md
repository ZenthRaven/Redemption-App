# Redemption

A gamified life operating system: finances, liabilities, habits, quests, calendar, learning, time, projects, health and life goals — one game you play to win.

Portrait Android app (Capacitor), developed as a web app with a phone-shaped live preview.

```bash
npm install
npm run dev
```

Open http://localhost:5173 — on desktop the app renders inside a phone frame with device presets; on a phone it fills the screen.

See [ROADMAP.md](ROADMAP.md) for the step-by-step build plan.
